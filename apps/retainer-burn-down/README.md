# Retainer Burn-Down Tracker

A no-login retainer tracker for freelancers. Configure a billing window, log time entries, and monitor remaining hours with a burn-down chart. Export a client-ready PDF summary anytime.

## Features
- Retainer setup (hours, hourly rate, start date, billing period)
- Time entry log with notes
- Remaining hours/value and burn-down chart
- Exportable PDF summary
- LocalStorage persistence

## Usage
1. Open `apps/retainer-burn-down/index.html` in a browser.
2. Set retainer details and click **Save settings**.
3. Log time entries as you work.
4. Use **Export client summary PDF** for sharing.

All data stays in your browser (localStorage).
