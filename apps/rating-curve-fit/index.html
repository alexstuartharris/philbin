Rating Curve Fit

Fit a simple power-law rating curve Q = a · (h − h0)^b from paired stage/discharge data. Everything runs locally in your browser (GitHub Pages-friendly). Upload a CSV, pick columns, set h0 (or auto-search it), then export parameters + a curve table.

Only points with h > h0 and Q > 0 are used.

Auto-search tries many h0 values below min(h) to minimize log-space SSE.

Tip: for quick testing, paste CSV into a file with columns like stage,discharge. If stage/discharge units vary (ft vs m), that’s fine—just be consistent.

This is a simple single-segment fit; real rating curves often need breaks, hysteresis handling, and error models. Treat outputs as exploratory unless you validate.

Model: fit is performed in log space: ln(Q) = ln(a) + b · ln(h − h0). Auto-search chooses h0 that minimizes log-space SSE. Want segmented curves / breaks? That’s a good next improvement.
