# Habit Streak Calendar

A personal productivity tracker for building daily streaks. Add habits, mark completions on a calendar, and keep simple stats with an exportable CSV.

## Features
- Add unlimited habits with color tags
- Daily completion toggles
- Calendar view with multi-habit dots
- Streak and best-streak counts
- CSV export
- LocalStorage persistence

## Usage
1. Open `apps/habit-streaks/index.html` in a browser.
2. Add a habit and select it as the active habit.
3. Click calendar days to toggle completions.
4. Export your history with **Export CSV**.

All data stays in your browser (localStorage).
